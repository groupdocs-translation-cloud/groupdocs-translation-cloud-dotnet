**Product features**

* Domain translation based on document classification using AI so that the result text or document will be translated with the respect of specific terminology.  
* Glossary integration into GroupDocs.Translation API.  
* Translation with respect to text tone using AI to preserve the emotional coloring and nuances of the original text.   
* Further AI features integration in Rewriter: CV optimization, grade essay estimation, video description generation, web page keywords generation.

**Team’s overview**

**GroupDocs.Translation:** during this semiannual period we will improve the quality of 10 language pairs, and we will integrate a multilanguage model that will allow us to increase the number of supported pairs with cross pair translation among them. Other features and improvements will include text alignment feature with awesome\_align library, optimization of ML service, implementation of priority queue.  
   
**GroupDocs.Rewriter:** as we do every semiannual period, we will add 3 new languages to rewriter, summarizer and synonymizer. Also we will continue to work on improvement and optimization of ML service by fixing memory leakage issues, adding batching to summarization and improving tokenizers for it. Also in priority will be further AI integration into the product. 

**Web applications:** our priority is to launch groupdocs.ai. We also plan to release web apps to all recently added features of GroupDocs.Translation and Rewriter either on groupdocs.app or on groupdocs.ai site.

**ChatGPT usage:** we plan to introduce 2 new features for Translation and 4 new features for Rewriter, that will use ChatGPT. In our everyday work it will be used for test data generation, textual content generation, unit tests and refactoring tasks. 

**Challenges** 

* Experiments with FastAPI by switching to threads instead of workers to improve performance.  
* Improvement of the simplifier feature of GroupDocs.Rewriter and adding more languages support.
